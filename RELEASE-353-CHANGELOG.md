# KVAS 1.1.9_beta-10-353

Локальный релиз на базе настоящей upstream-ветки main. Пакет на роутер не
устанавливался.

## Изменения

- Для готовности VPN требуются state=up, link=up и connected=yes.
- При ошибке создания таблицы маршрутизации или маршрута маркировка не
  включается.
- Для VLESS Proxy21 не создаётся искусственный вспомогательный маршрут /24.
- Для VLESS используется установленная на роутере служба S97xray.
- Сохранено RULE_PRIORITY=99, соответствующее рабочему beta-10-352.
- Добавлены локальные тесты и воспроизводимый сборщик IPK.

## Ограничения

Роутерная конфигурация, DNS, маршруты и выбранный VPN не изменялись. Без
отдельного тестирования на роутере с подтверждённым откатом этот релиз нельзя
считать готовым к установке.
