# Ручной план отката KVAS 353

Процедура предназначена для будущей ручной установки и не выполняется
скриптами сборки.

## До установки

1. Оставить рабочий OpenVPN выбранным резервным подключением.
2. Сохранить текущие файлы KVAS, Xray, DNS-посредника, обработчиков и rescue.
3. Подготовить заведомо рабочий IPK beta-10-352 и проверить checksum.
4. Обеспечить независимый доступ через консоль или LAN.
5. Зафиксировать WAN-интерфейс, шлюз, default route и прямой доступ в интернет.

## Откат

Не переключать VPN повторно. Из независимой консоли или SSH выполнить:

    opkg install /opt/tmp/kvas_1.1.9_beta-10-352_all.ipk

Затем восстановить локальные ссылки S97xray и файлы из резервной копии,
перезапустить только затронутые службы и проверить WAN, DNS и OpenVPN.

При изменении default route, недоступности шлюза, отказе LAN DNS или потере SSH
немедленно прекратить эксперименты и использовать независимый путь восстановления.
Не выполнять очистку всех маршрутов/iptables и не удалять Proxy21 первым действием.
